# EsportHub Project

Цей проєкт складається з клієнтської частини (React), серверної частини (Node.js/Express) та бази даних (MySQL), які об'єднані та налаштовані для роботи через Docker Compose.

## Структура проєкту

- `/client` — Frontend (React)
- `/server` — Backend (Node.js, Express)
- `docker-compose.yaml` — Конфігураційний файл для запуску всіх сервісів
- `.env` — Файл зі змінними оточення (паролі, порти тощо)

## Вимоги для запуску

Для локального запуску проєкту на вашому комп'ютері має бути встановлено:
* **Docker** та **Docker Desktop** (запущений у фоні).

## Інструкція із запуску

1. Склонуйте або завантажте проєкт на свій комп'ютер.
2. Переконайтеся, що файл `.env` знаходиться в корені проєкту (якщо його немає, створіть на основі `.env.example`).
3. Відкрийте термінал у кореневій папці проєкту (там, де лежить файл `docker-compose.yaml`).
4. Виконайте команду для збірки та запуску всіх контейнерів:

```bash
docker-compose up --build
````

5.  Дочекайтеся завершення збірки. Якщо все пройшло успішно, сервіси будуть доступні за такими адресами.

## Доступні сервіси (Порти)

Після успішного запуску ви можете відкрити у браузері наступні посилання:

  * **Frontend (React UI):** [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000)
  * **Backend API (Swagger Docs):** [http://localhost:5000/api/docs](https://www.google.com/search?q=http://localhost:5000/api/docs)
  * **Admin Tool (phpMyAdmin):** [http://localhost:8080](https://www.google.com/search?q=http://localhost:8080)
  * **MySQL Database:** підключення на порту `3306` (внутрішній доступ для контейнерів)

## Як зупинити проєкт

Щоб зупинити роботу сервісів, натисніть `Ctrl + C` у терміналі, де працює Docker, або виконайте команду:

```bash
docker-compose down
```
